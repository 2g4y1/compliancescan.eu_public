# compliancescan.eu — Public Issue Tracker

This is the **public issue tracker** for [compliancescan.eu](https://compliancescan.eu), a compliance scanning tool. The source code lives in a private repository; this public repository exists solely so that users can report bugs and request features.

## How to use this tracker

- **Bug reports** — If something is not working as expected, please [open a bug report](../../issues/new?template=bug_report.yml).
- **Feature requests** — Have an idea for an improvement? Please [open a feature request](../../issues/new?template=feature_request.yml).

Before opening a new issue, please [search existing issues](../../issues) to avoid duplicates.

## What belongs here

| ✅ Appropriate | ❌ Not appropriate |
|---|---|
| Bug reports | Support questions (use [Discussions](../../discussions) instead) |
| Feature requests | Security vulnerabilities (see [Security](#security) below) |
| Usability feedback | General conversation |

## Security

**Please do not report security vulnerabilities through public GitHub issues.**

If you discover a security vulnerability, please send an email to **security@compliancescan.eu**. You will receive a response within 2 business days (Monday–Friday, CET/CEST). We appreciate your responsible disclosure.
